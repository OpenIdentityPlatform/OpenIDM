The historical Scripted SAP connector used the Groovy Connector Toolkit and the SAP Java Connector (JCo) to connect to SAP HR and SAP R/3. The current OpenIDM distribution and Java OpenICF releases do not provide the SAP connector JAR or the matching scripts and provisioner configurations.

If you maintain an older deployment, obtain the connector artifacts from your original distribution and check the corresponding SAP JCo requirements, including architecture and native library compatibility. Use xref:../integrators-guide/chap-resource-conf.adoc#connector-wiz-cli[the REST connector configuration tools] with your installed bundle to inspect the properties that its version exposes.

For a new integration, see xref:chap-groovy.adoc#chap-groovy[Groovy Connector Toolkit] for the available scripting interfaces. A custom SAP integration requires its own tested scripts and a supported JCo version.
