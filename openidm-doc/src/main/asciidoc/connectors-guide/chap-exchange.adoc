[#chap-exchange]
== Legacy Microsoft Exchange Connector

The OpenIDM release ZIP excludes the Exchange connector. Download link:https://github.com/OpenIdentityPlatform/OpenICF.Net/releases/download/1.5.0/Exchange.Connector-1.5.0.0.zip[Exchange.Connector-1.5.0.0.zip] from OpenICF.Net. The connector extends the legacy Active Directory connector to provision on-premises Exchange recipients. Its runspace recognizes the Exchange 2007 and 2010 PowerShell snap-ins.

[#exchange-connector-config]
=== Install and Configure the Connector

. Install the link:https://github.com/OpenIdentityPlatform/OpenICF.Net/releases/tag/1.5.0[Windows .NET Connector Server] on a host with the applicable Exchange management tools and registered PowerShell snap-in. The Connector Server service account needs permission to run the Exchange cmdlets. See the link:https://github.com/OpenIdentityPlatform/OpenICF.Net/wiki/Installing-and-Configuring-a-.NET-Connector-Server[.NET Connector Server installation instructions].
. Extract the Exchange connector ZIP into the Connector Server installation directory, preserving the locale subdirectories. The ZIP contains `Exchange.Connector.dll` and its dependencies, including `ActiveDirectory.Connector.dll`. Restart the Connector Server service after installing the files.
. Set up the xref:../integrators-guide/chap-resource-conf.adoc#connector-info-provider-conf[remote connector server configuration] in OpenIDM. Set `connectorHostRef` to the name of that server, then use the xref:../integrators-guide/chap-resource-conf.adoc#connector-wiz[connector configuration tools] to discover the bundle and generate its provisioner. Use the following connector reference for release 1.5.0.
+
[source,json]
----
{
  "connectorHostRef": "dotnet",
  "connectorName": "Org.IdentityConnectors.Exchange.ExchangeConnector",
  "bundleName": "Exchange.Connector",
  "bundleVersion": "1.5.0.0"
}
----
. Set `configurationProperties` using the xref:chap-ad.adoc#ad-connector-config[Active Directory configuration reference]. `ExchangeConfiguration` inherits all Active Directory settings, including `DomainName`, `Container`, `DirectoryAdminName`, and `DirectoryAdminPassword`. Exchange cmdlets run through the local PowerShell runspace on the Connector Server host.
. Test the provisioner with `POST /openidm/system/<provisioner-name>?_action=test`. The connector checks its Active Directory connection and whether the Exchange runspace is open.

[#exchange-provision-recipients]
=== Provision Exchange Recipients

On the `__ACCOUNT__` object type, set `RecipientType` when creating an account. Use `UserMailbox` for an Exchange mailbox, `MailUser` for a mail-enabled user with an external address, or `User` for an Active Directory account without Exchange provisioning.

`Database` identifies the mailbox database. `ExternalEmailAddress` supplies the external address for a mail-enabled user. When configuring searches or synchronization, request these Exchange attributes explicitly if the mapping uses them. The schema marks `RecipientType`, `Database`, and `ExternalEmailAddress` as absent from default results. Synchronization follows the Active Directory change stream.

See the link:https://github.com/OpenIdentityPlatform/OpenICF.Net/tree/1.5.0/dotnet-connector/ExchangeConnector[Exchange connector source] for the schema and the PowerShell commands associated with each recipient type.
