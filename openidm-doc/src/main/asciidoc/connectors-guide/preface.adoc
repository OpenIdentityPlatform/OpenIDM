== Preface

Use this guide to install and configure OpenICF connectors for OpenIDM. See xref:chap-overview.adoc#chap-overview[the connector overview] for the contents of the release ZIP and sources for separately distributed connectors.

The link:https://github.com/OpenIdentityPlatform/OpenICF/wiki/Connectors-Guide[OpenICF Connectors Guide] describes the framework and its connectors. For legacy deployments, the wiki also links to the OpenICF 1.5 configuration reference and the OpenIDM 4.5 Connectors Guide.

[#d8013e155]
=== Who Should Use This Guide

This guide is for administrators and integrators configuring connectors for an OpenIDM deployment. Familiarity with identity management and with administering the target system helps when setting up and troubleshooting a connection.
