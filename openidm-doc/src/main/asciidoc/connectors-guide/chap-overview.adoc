[#chap-overview]
== OpenIDM Connector Overview

The release ZIP installs seven Java connector bundles in `openidm/connectors/`. The JAR names identify the bundled OpenICF version. The same bundles are available from link:https://github.com/OpenIdentityPlatform/OpenICF/releases[OpenICF releases] for deployment on a remote Java connector server.

Generate a provisioner configuration using xref:../integrators-guide/chap-resource-conf.adoc#connector-wiz[the connector configuration tools], or start from a file in `openidm/samples/provisioners/`. A sample configuration can reference a separately distributed connector. To see bundles loaded by OpenIDM and by its configured remote connector servers, use `POST /openidm/system?_action=availableConnectors`.

[#connectors-provided-with-openidm]
=== Connectors Provided With OpenIDM

[cols="2,3,4",options="header"]
|===
|Connector |Artifact |Typical use
|xref:chap-ldap.adoc#chap-ldap[LDAP] |`ldap-connector` |Provision to and synchronize with LDAPv3 directories, including OpenDJ and Active Directory Domain Services.
|xref:chap-csv.adoc#chap-csv[CSV file] |`csvfile-connector` |Work with identities in a delimited flat file.
|xref:chap-database.adoc#chap-database[Database table] |`databasetable-connector` |Provision to a single table through JDBC.
|xref:chap-groovy.adoc#chap-groovy[Groovy Toolkit] |`groovy-connector` |Implement operations with xref:chap-groovy.adoc#scripted-groovy[Scripted Groovy], xref:chap-groovy.adoc#scripted-poolable-groovy[Scripted Poolable Groovy], xref:chap-groovy.adoc#scripted-sql[Scripted SQL], xref:chap-groovy.adoc#scripted-rest[Scripted REST], or xref:chap-groovy.adoc#scripted-crest[Scripted CREST].
|xref:chap-ssh.adoc#chap-ssh[SSH] |`ssh-connector` |Run scripted operations through SSH. Supply operation scripts for the target system.
|xref:chap-kerberos.adoc#chap-kerberos[Kerberos] |`kerberos-connector` |Manage Kerberos principals using the included `kadmin` scripts.
|xref:chap-xml.adoc#chap-xml[XML file] |`xml-connector` |Run local demonstrations that store identities in an XML file.
|===
