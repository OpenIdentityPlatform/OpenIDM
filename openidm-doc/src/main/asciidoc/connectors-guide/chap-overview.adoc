[#chap-overview]
== Overview of the Connectors Supported With OpenIDM {openidm-version-short}

The release ZIP installs seven Java connector bundles in `openidm/connectors/`. File names include the bundled OpenICF version. For the exact version, inspect the ZIP or the installed JAR names. Build a provisioner with xref:../integrators-guide/chap-resource-conf.adoc#connector-wiz[the connector configuration tools].

[#connectors-provided-with-openidm]
=== Connectors Provided With OpenIDM

[cols="2,3,4",options="header"]
|===
|Connector |Artifact |Typical use
|xref:chap-ldap.adoc#chap-ldap[LDAP] |`ldap-connector` |Provision to and synchronize with LDAPv3 directories, including OpenDJ and Active Directory Domain Services.
|xref:chap-csv.adoc#chap-csv[CSV file] |`csvfile-connector` |Work with identities in a delimited flat file.
|xref:chap-database.adoc#chap-database[Database table] |`databasetable-connector` |Provision to a single table through JDBC.
|xref:chap-groovy.adoc#chap-groovy[Groovy Toolkit] |`groovy-connector` |Implement connector operations with scripts, including Scripted REST, CREST, and SQL.
|xref:chap-ssh.adoc#chap-ssh[SSH] |`ssh-connector` |Run scripted operations through SSH. Supply operation scripts for the target system.
|xref:chap-kerberos.adoc#chap-kerberos[Kerberos] |`kerberos-connector` |Manage Kerberos principals using the included `kadmin` scripts.
|xref:chap-xml.adoc#chap-xml[XML file] |`xml-connector` |Run local demonstrations that store identities in an XML file.
|===

The xref:chap-powershell.adoc#chap-powershell[PowerShell Toolkit] and xref:chap-ad.adoc#chap-ad[legacy Active Directory connector] are separate OpenICF.Net downloads and require a Windows connector server. The xref:chap-sap.adoc#chap-sap[SAP], xref:chap-google.adoc#chap-google[Google Apps], and xref:chap-salesforce.adoc#chap-salesforce[Salesforce] pages document historical integrations.
