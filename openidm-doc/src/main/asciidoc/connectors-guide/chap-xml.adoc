[#chap-xml]
== XML File Connector

OpenIDM ships `connectors/xml-connector-<version>.jar` for demonstrations using XML files that follow the connector schema. For a custom XML format, use the xref:chap-groovy.adoc#chap-groovy[Groovy Connector Toolkit] to implement the required operations.

[#xml-connector-config]
=== Configuring the XML File Connector

Use the template `samples/provisioners/provisioner.openicf-xml.json` to configure a new resource. The OpenIDM `samples/workflow` project contains a working provisioner with the three files used below in its `data/` directory.

[source, json]
----
{
    "connectorRef": {
        "bundleName" : "org.openidentityplatform.openicf.connectors.xml-connector",
        "bundleVersion" : "[2.0.0.0,3)",
        "connectorName" : "org.forgerock.openicf.connectors.xml.XMLConnector"
    },
    "configurationProperties": {
        "xsdIcfFilePath" : "&{launcher.project.location}/data/resource-schema-1.xsd",
        "xsdFilePath" : "&{launcher.project.location}/data/resource-schema-extension.xsd",
        "xmlFilePath" : "&{launcher.project.location}/data/xmlConnectorData.xml"
    }
}
----
`&{launcher.project.location}` resolves to the OpenIDM project directory, such as `openidm/samples/workflow`. For a remote connector server, add its `connectorHostRef` to `connectorRef` and use absolute paths on that host. The process running the connector needs read access to the schemas and read and write access to the XML data file.

[#xml-connector-properties]
==== Configuration Properties

[cols="2,1,1,4",options="header"]
|===
|Property |Type |Default |Purpose
|`xsdIcfFilePath` |Path |Unset |Path to the standard OpenICF resource schema. Supply `resource-schema-1.xsd` from the sample when configuring the bundled connector. The custom XSD imports this schema.
|`xsdFilePath` |Path |Unset |Required path to the custom XSD defining the attributes and object classes exposed by the connector.
|`xmlFilePath` |Path |Unset |Required path to the XML data file. It must conform to the configured schemas.
|`createFileIfNotExists` |Boolean |`false` |Set to `true` to initialize a missing store at `xmlFilePath`. Give the connector process permission to create the data file.
|===

[#xml-connector-operations]
=== Using the XML File Connector

The XML connector supports create, update, delete, search, schema discovery, connection testing, and authentication for accounts. Use reconciliation to discover changes to the XML file. LiveSync is unavailable because the connector implements no Sync operation.

For a walkthrough using the bundled XML resource, see xref:../samples-guide/chap-workflow-samples.adoc#example-provisioning-workflow[the provisioning workflow sample].
