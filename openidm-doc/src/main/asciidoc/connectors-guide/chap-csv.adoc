[#chap-csv]
== CSV File Connector

The CSV file connector manages accounts in a delimited file. Use reconciliation for an initial import or a comparison of the full data set. Use LiveSync to detect changes between file snapshots.

[#csv-connector-config]
=== Configuring the CSV File Connector

OpenIDM ships `connectors/csvfile-connector-<version>.jar` and a configuration template at `samples/provisioners/provisioner.openicf-csv.json`. The xref:../getting-started/chap-openidm-demo.adoc#chap-openidm-demo[Getting Started sample] includes a runnable CSV configuration and an example of reconciling a changed record.

The following example combines the connector reference and file settings. For a remote connector server, add its `connectorHostRef` to `connectorRef` and set `csvFile` to an absolute path on that host.

[source, json]
----
{
  "connectorRef": {
    "bundleName"    : "org.openidentityplatform.openicf.connectors.csvfile-connector",
    "bundleVersion" : "[2.0.0.0,3)",
    "connectorName" : "org.forgerock.openicf.csvfile.CSVFileConnector"
  },
  "configurationProperties": {
    "csvFile": "&{launcher.project.location}/data/hr.csv",
    "headerUid": "uid"
  }
}
----

Create the file with a header row before starting the connector. Give the connector process read and write access to the file, and permission to create files in its directory for provisioning and LiveSync. Use the JVM's default charset. Use unique, nonempty values in the column selected by `headerUid`.

The connector handles the `+__ACCOUNT__+` object class. The UID column maps to `+__UID__+` and `+__NAME__+`. Other data columns are exposed as strings, except the configured password column.

[#csv-connector-livesync]
=== Detecting Changes to the CSV File

LiveSync uses the sync token to find a previous copy stored next to the configured file. The connector compares rows by their UID column and reports creations, updates, and deletions. Supply a full snapshot at each refresh. A row omitted from a partial export is treated as deleted.

If the token is missing or its snapshot is unavailable, the connector establishes a new baseline from the current file. Run reconciliation to recover changes across a missing baseline. Keep the file name, headers, and UID values stable across refreshes.

[#sec-implemented-interfaces-org-forgerock-openicf-csvfile-CSVFileConnector-1_5_1_4]
=== OpenICF Interfaces Implemented by the CSV File Connector

The CSV File Connector implements the following OpenICF interfaces.
--

xref:appendix-interfaces.adoc#interface-AuthenticationApiOp[Authenticate]::
Authenticates an account using its UID and the value in the configured password column.

xref:appendix-interfaces.adoc#interface-BatchApiOp[Batch]::
Execute a series of operations in a single request.

xref:appendix-interfaces.adoc#interface-CreateApiOp[Create]::
Creates an object and its `uid`.

xref:appendix-interfaces.adoc#interface-DeleteApiOp[Delete]::
Deletes an object, referenced by its `uid`.

xref:appendix-interfaces.adoc#interface-ResolveUsernameApiOp[Resolve Username]::
Resolves an object by its username and returns the `uid` of the object.

xref:appendix-interfaces.adoc#interface-SchemaApiOp[Schema]::
Describes the object types, operations, and options that the connector supports.

xref:appendix-interfaces.adoc#interface-ScriptOnConnectorApiOp[Script on Connector]::
Enables an application to run a script in the context of the connector. Any script that runs on the connector has the following characteristics:
+

* The script runs in the same execution environment as the connector and has access to all the classes to which the connector has access.

* The script has access to a `connector` variable that is equivalent to an initialized instance of the connector. At a minimum, the script can access the connector configuration.

* The script has access to any script-arguments passed in by the application.


xref:appendix-interfaces.adoc#interface-SearchApiOp[Search]::
Searches the target resource for all objects that match the specified object class and filter.

xref:appendix-interfaces.adoc#interface-SyncApiOp[Sync]::
Polls the target resource for synchronization events, that is, native changes to objects on the target resource.

xref:appendix-interfaces.adoc#interface-TestApiOp[Test]::
Validates access to the file and its configured header.

xref:appendix-interfaces.adoc#interface-UpdateApiOp[Update]::
Updates (modifies or replaces) objects on a target resource.

--


[#sec-config-properties-org-forgerock-openicf-csvfile-CSVFileConnector-1_5_1_4]
=== CSV File Connector Configuration

The CSV File Connector has the following configurable properties.

[#configuration-properties-org-forgerock-openicf-csvfile-CSVFileConnector-1_5_1_4]
==== Configuration Properties


[cols="2,1,1,4",options="header"]
|===
|Property |Type |Default |Purpose
|`csvFile` |Path |Unset |Required path to the CSV file.
|`headerUid` |String |`uid` |Header column used as the account identifier and name.
|`headerPassword` |String |`password` |Header column used for `+__PASSWORD__+` and password-based authentication. Use a file without a password column for identity imports that require only account attributes.
|`fieldDelimiter` |String |`,` |Field separator. The connector uses the first character.
|`quoteCharacter` |String |`"` |Field quote character. The connector uses the first character.
|`newlineString` |String |`\n` |Line terminator emitted when writing records.
|`syncFileRetentionCount` |Integer |`3` |Number of historical copies to retain during LiveSync. Keep sufficient history for the interval between successful polls and retries.
|===
