[#appendix-interfaces]
== OpenICF Interfaces

The OpenICF Java API exposes operations through `ConnectorFacade`. Connectors implement the corresponding service provider interfaces (SPI). The operations available for a provisioner depend on its connector, object type, and configuration. Use the connector schema to discover supported operations and options.

[#interface-attributeNormalizer]
=== AttributeNormalizer

`AttributeNormalizer` is an optional SPI hook. The framework can apply it to filter operands, input attributes, and results so that values are compared consistently.


[#interface-AuthenticationApiOp]
=== Authenticate

`AuthenticationApiOp` delegates to `AuthenticateOp` to authenticate with a username and password. OpenIDM pass-through authentication requires this operation.


[#interface-BatchApiOp]
=== Batch

`BatchApiOp` submits multiple tasks to a connector. A connector can implement `BatchOp` for native batching and for querying an outstanding batch. The local Java facade can also execute a batch of supported operations sequentially using individual connector calls.


[#interface-ConnectorEventSubscriptionApiOp]
=== Connector Event

`ConnectorEventSubscriptionApiOp` delegates to `ConnectorEventSubscriptionOp` to receive resource-specific events from connectors that support subscriptions. The transport must also support subscriptions for a remote connector.


[#interface-CreateApiOp]
=== Create

`CreateApiOp` delegates to `CreateOp` to create an object and return its `Uid`.


[#interface-DeleteApiOp]
=== Delete

`DeleteApiOp` delegates to `DeleteOp` to delete an object by its `Uid`.


[#interface-GetApiOp]
=== Get

`GetApiOp` retrieves an object by its `Uid`. The local Java facade implements this by searching for that identifier through `SearchOp`.


[#interface-PoolableConnector]
=== PoolableConnector

`PoolableConnector` enables OpenICF to reuse connector instances. See xref:appendix-pooling.adoc#appendix-pooling[Connection Pooling Configuration].


[#interface-ResolveUsernameApiOp]
=== Resolve Username

`ResolveUsernameApiOp` delegates to `ResolveUsernameOp` to resolve a username to a `Uid`.


[#interface-SchemaApiOp]
=== Schema

`SchemaApiOp` delegates to `SchemaOp` to describe the supported object types, attributes, operations, and options.


[#interface-ScriptOnConnectorApiOp]
=== Script on Connector

`ScriptOnConnectorApiOp` executes a script in the connector runtime. The runtime is on the connector server when the connector is remote.


[#interface-ScriptOnResourceApiOp]
=== Script On Resource

`ScriptOnResourceApiOp` delegates to `ScriptOnResourceOp` to run a script on the target resource. The connector determines the supported languages and options.


[#interface-SearchApiOp]
=== Search

`SearchApiOp` delegates to `SearchOp` to query resource objects. Search enables reads and source-side reconciliation. Provisioning writes and polling for changes require the corresponding operations.


[#interface-SyncApiOp]
=== Sync

`SyncApiOp` delegates to `SyncOp` to poll for changes on the resource. The connector returns deltas and a synchronization token that the caller uses to resume polling.


[#interface-SyncEventSubscriptionApiOp]
=== Sync Event

`SyncEventSubscriptionApiOp` delegates to `SyncEventSubscriptionOp` to subscribe to changes on connectors and transports that support streaming synchronization.


[#interface-TestApiOp]
=== Test

`TestApiOp` delegates to `TestOp` to check the configuration by running connector-specific checks, typically including a connection to the resource.


[#interface-UpdateApiOp]
=== Update

`UpdateApiOp` updates an existing resource object and returns its `Uid`. The `UpdateOp` SPI replaces the values of supplied attributes.


[#interface-UpdateAttributeValuesOp]
=== Update Attribute Values

`UpdateAttributeValuesOp` extends `UpdateOp` with methods to add or remove individual values. A resource that supports these changes directly can apply them without reading and replacing the complete attribute.

[#interface-ValidateApiOp]
=== Validate

`ValidateApiOp` calls the connector configuration's validation method. Use Test for connector-specific connectivity checks.
