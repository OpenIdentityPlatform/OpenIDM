[#chap-ssh]
== Scripted SSH Connector

The Scripted SSH Connector runs Groovy operation scripts in an interactive SSH shell. It uses JSch for the SSH session and Expect4j for matching prompts and output. OpenIDM includes `openidm/connectors/ssh-connector-<version>.jar`. The bundle name is `org.openidentityplatform.openicf.connectors.ssh-connector` and the connector class is `org.forgerock.openicf.connectors.ssh.SSHConnector`.

Each pooled connector instance keeps its own SSH connection and shell. Later actions can reuse the same shell state. Scripts should leave the session ready for the next operation. Configure the provisioner's `poolConfigOption` as described in xref:appendix-pooling.adoc#appendix-pooling[Connection Pooling Configuration].

[#ssh-authentication]
=== Configuring Authentication to the SSH Server

Set one of the following configurations under `configurationProperties` in the provisioner file.

For password authentication, set `authenticationType` to `PASSWORD` and specify the SSH login and password.

[source,json]
----
{
  "authenticationType": "PASSWORD",
  "user": "<SSH USER>",
  "password": "<SSH PASSWORD>"
}
----

For public-key authentication, authorize the public key for the SSH account on the server. Supply the associated private key in a PEM format accepted by the connector's JSch library, with one JSON string per line. Include an empty string for the `passphrase` when the key has none.

[source,json]
----
{
  "authenticationType": "PUBKEY",
  "user": "<SSH USER>",
  "password": "<SUDO PASSWORD>",
  "passphrase": "<KEY PASSPHRASE>",
  "privateKey": ["<BEGIN LINE>", "<KEY CONTENT>", "<END LINE>"]
}
----

The connector validates that `password` is supplied in both modes. In public-key mode it authenticates the SSH connection with the key, and the `sudo` helper uses `password` if called by a script. The `password`, `passphrase`, and `privateKey` properties are confidential.

OpenICF 2.0.4 opens the SSH session with host key verification disabled for both authentication modes. Use an independently authenticated network path to the target if you deploy this connector. See the link:https://github.com/OpenIdentityPlatform/OpenICF/blob/2.0.4/OpenICF-ssh-connector/src/main/java/org/forgerock/openicf/connectors/ssh/SSHConnection.java[SSH session implementation].

[#ssh-connector-config]
=== Configuring the SSH Connector

. Copy `samples/provisioners/provisioner.openicf-ssh.json` to your project's `conf/` directory and set the SSH connection properties. Use an account allowed to start an interactive shell. Set `prompt` to the shell's stable prompt, including any trailing space. The sample expects operation scripts in the project's `tools/` directory.
. Supply and review the operation scripts. The link:https://github.com/OpenIdentityPlatform/OpenICF/tree/2.0.4/OpenICF-ssh-connector/src/test/groovy/samples/linux/scripts[OpenICF Linux test scripts] demonstrate the operation bindings and include a shared `ErrorCodes.groovy` helper. Use the tag matching your installed connector and adapt the scripts to the target commands and required permissions.
. Start OpenIDM. As an authorized user, run `POST /openidm/system/ssh?_action=test`, confirm `"ok": true`, and call a read-only query such as `GET /openidm/system/ssh/account?_queryId=query-all-ids` before enabling writes. Use the configured provisioner name and object type if they differ from the sample.

The connector binds `connection` and shell helpers to the scripts. Use `sendln` to send a line, `expect` to wait for a prompt or output, and `promptReady` to check whether the shell is ready. The `sudo` helper waits for a password prompt and sends the configured password. Scripts that use this helper require a corresponding password-prompting sudo rule on the SSH host.

[#sec-implemented-interfaces-org-forgerock-openicf-connectors-ssh-SSHConnector-1_4_0_0]
=== OpenICF Interfaces Implemented by the SSH Connector

The SSH connector implements the xref:chap-groovy.adoc#sec-implemented-interfaces-org-forgerock-openicf-connectors-groovy-ScriptedConnector-1_4_2_1[shared Groovy interfaces] and supports OpenICF instance pooling. Configured operation scripts and their schema determine which operations are available on each object type. The sample expects scripts for create, update, delete, search, schema, test, and script-on-resource.

[#sec-config-properties-org-forgerock-openicf-connectors-ssh-SSHConnector-1_4_0_0]
=== SSH Connector Configuration

Use xref:../integrators-guide/chap-resource-conf.adoc#connector-wiz-cli[`createCoreConfig`] to inspect the properties of the installed connector. The connector also inherits xref:chap-groovy.adoc#configuration-properties-org-forgerock-openicf-connectors-groovy-ScriptedConnector-1_4_2_1[the shared custom configuration properties].

[#configuration-properties-org-forgerock-openicf-connectors-ssh-SSHConnector-1_4_0_0]
==== Configuration Properties

[cols="3,2,2,3,6",options="header"]
|===
|Property |Type |Default |Required |Purpose
| `host` | String | Unset | Yes | SSH hostname or IP address.
| `port` | Integer | `22` | Yes | SSH server port.
| `user` | String | Unset | Yes | SSH login.
| `authenticationType` | String | `PASSWORD` | Yes | Select `PASSWORD` or `PUBKEY`.
| `password` | GuardedString | Unset | Yes | Confidential SSH login password or password for scripts that call `sudo`. Validation requires a configured value for both modes.
| `passphrase` | GuardedString | Unset | In `PUBKEY` mode | Confidential private key passphrase. Use an empty string for a key without a passphrase.
| `privateKey` | String[] | `[]` | In `PUBKEY` mode | Confidential PEM key with one element per line.
| `prompt` | String | `root@localhost:# ` | Yes | Shell prompt, including any trailing space.
| `sudoCommand` | String | `/usr/bin/sudo` | Yes | Path to the command used by the `sudo` helper.
| `echoOff` | Boolean | `true` | Yes | Disable input echo in the remote shell. With echo enabled, scripts may receive their commands in the terminal output.
| `terminalType` | String | `vt102` | Yes | Remote pseudo-terminal type.
| `connectionTimeout` | Integer | `5000` | Yes | Timeout for opening the SSH session and shell channel. With OpenICF 2.0.4, the connector multiplies this value by 1000 before passing it to JSch in milliseconds.
| `expectTimeout` | Long | `5000` | Yes | Default timeout in milliseconds for script calls to `expect`.
| `throwOperationTimeoutException` | Boolean | `true` | Yes | Throw `OperationTimeoutException` on an Expect timeout. Set to `false` to return the timeout status code for the script to handle.
| `setLocale` | Boolean | `false` | Yes | Exposed for locale selection. The standard OpenICF 2.0.4 SSH connection path leaves the shell locale unchanged.
| `locale` | String | `en_US.utf8` | Yes | Locale value accepted by the configuration. Set the locale on the SSH host for scripts that depend on command output.
|===

[#operation-script-files-properties-org-forgerock-openicf-connectors-ssh-SSHConnector-1_4_0_0]
==== Operation Script Files Properties

See xref:chap-groovy.adoc#operation-script-files-properties-org-forgerock-openicf-connectors-groovy-ScriptedConnector-1_4_2_1[Operation Script Files Properties] for the inherited filenames. An optional `customizerScriptFileName` can define SSH lifecycle hooks such as `onCreateConnection` and `onCloseConnection`.

[#groovy-engine-configuration-properties-org-forgerock-openicf-connectors-ssh-SSHConnector-1_4_0_0]
==== Groovy Engine Configuration Properties

See xref:chap-groovy.adoc#groovy-engine-configuration-properties-org-forgerock-openicf-connectors-groovy-ScriptedConnector-1_4_2_1[Groovy Engine Configuration Properties] for the inherited compiler settings. Set `scriptRoots` explicitly and use `classpath` for any additional script dependencies.

Some sample provisioners carry the old `reloadScriptOnExecution` setting. The 2.0.4 connector ignores it. Use `recompileGroovySource` and `minimumRecompilationInterval` for compiler configuration.

[#basic-configuration-properties-properties-org-forgerock-openicf-connectors-ssh-SSHConnector-1_4_0_0]
==== Basic Configuration Properties

Set the connection and authentication properties listed in xref:#configuration-properties-org-forgerock-openicf-connectors-ssh-SSHConnector-1_4_0_0[Configuration Properties]. Tune the SSH connection timeout and the script's Expect timeout independently.
