# Historical Azure AD PowerShell sample

These files document a historical integration through MSOnline. Microsoft retired MSOnline in 2025. The sample scripts cannot connect to a current Microsoft Entra ID tenant.

For a new integration, see the [Microsoft Graph PowerShell migration guide](https://learn.microsoft.com/powershell/microsoftgraph/migration-steps). Replace the operation scripts, configure application authentication and permissions, and test against a disposable tenant. The separate `powershell2AD` sample targets Active Directory Domain Services.
